# 2026-09 UI/UX 개선

기존 노란색 테마와 캐릭터를 유지하면서 정보 위계, 모바일 조회, 입력과 복구 흐름을 정리했습니다. 금융 계산과 저장 API는 그대로 사용하며 추가 DB 마이그레이션은 없습니다.

## 주요 변경

- 공통 헤더: 현재 날짜·화면별 안내, 조회 기준 선택, 처리 중 새로고침 표시.
- 메뉴: 현재 화면 표시, 본문 건너뛰기, 모바일 펼침/접기, Escape로 닫은 뒤 버튼으로 포커스 복귀.
- 표·차트: 화면 폭 안에서 스크롤, 넓은 표의 첫 열 고정, 실제 넘치는 영역에 키보드 이동과 안내 제공. 날짜와 금액은 줄바꿈하지 않으며 메모는 줄바꿈합니다.
- 모달: 입력창 2열/모바일 1열, 긴 본문 내부 스크롤, 고정된 헤더·하단, 오류 메시지로 포커스 이동. 일반 저장 중 중복 제출과 닫기 방지.
- 로딩·오류: 초기 조회 실패 시 다시 불러오기, 연결 실패 안내, 저장 성공 후 화면 조회 실패를 구분.
- 대시보드: 순자산 강조, 금액 설명, 자주 쓰는 화면 바로가기, 월 수입·지출·차액 표시.
- 거래내역: 이름이 붙은 검색 필드, 이번 달/지난달/최근 3개월, 조건 초기화, Enter 검색, 기간 오류, 조회 조건·결과 개수, 빈 검색 결과 안내. 15건 페이징 유지.
- 예정 거래: 달력/날짜별 목록 선택, 모바일 기본 목록, 미처리·완료 건수. 기존 결제 계좌 단위 카드대금 흐름을 재사용합니다.
- 증권: 계좌·보유종목을 먼저 확인하고 주문으로 이동하는 구성과 구역 바로가기.
- 주문: 입력→확인→결과 단계, 주문 방식에 맞는 설명, 상태 표시, 입력값을 유지한 수정·가격 재조회. 확인 시간이 만료되면 전송하지 않고 다시 확인하도록 안내합니다. 응답 유실 시 자동 재전송하지 않습니다.
- 설정: KIS 주문 활성화 여부와 실전/모의 상태 표시.

## 추가 사용성 개선

- 증권은 보유 종목을 기본 화면으로 하고 주문·계좌·등락률 이력·자산 추이를 별도 탭으로 구성했습니다. URL 해시로 현재 탭을 유지하고 방향키/Home/End로 이동합니다. 계좌 상세 내부 탭과 식별자를 분리했습니다.
- 증권 총자산·종목 수·계좌 수를 먼저 보여주며, 종목명/코드 검색을 지원합니다. 비중 차트는 접어서 보유 종목을 먼저 확인할 수 있습니다.
- 모바일 보유 종목·증권계좌·거래내역은 핵심 항목을 카드로 표시하고 추가 항목을 펼칩니다. 데스크톱은 전체 표와 정렬을 유지합니다.
- 모바일 하단에는 홈·거래내역·증권·예정 거래 바로가기를 두고 안전 영역과 본문 하단 여백을 확보했습니다. 사이드 메뉴에는 공통 SVG 아이콘을 사용합니다.
- 거래 검색 조건은 같은 탭 세션에서 화면 이동/새로고침 후에도 유지합니다. 조회 실패와 빈 결과를 구별하고, 이전 조회 결과가 남아 있을 때 이를 명시합니다.
- 편집 창은 입력란, 상세/확인 창은 제목으로 포커스를 이동합니다. 자산 기록 저장 후 화면 조회 실패는 저장 자체 실패와 구별합니다.

## 검증 명령

`node tests/page-modules.cjs`: 11개 화면 모듈, 금액·표·정렬·페이지 계산.

`node tests/decimal.cjs`: `0E-8` 같은 BigDecimal 지수 표기, 큰 금액의 정밀도와 소수 8자리 절삭. 금액 자체를 JavaScript Number로 바꾸지 않고 처리합니다.

`node tests/securities-loading-browser.cjs`: 지수 표기 실제 응답 형태, 주문·이력의 부분 조회 실패에도 보유종목 유지, 구역별 재시도와 소유자 전환. 주문 조회의 `JOINT`는 계좌 소유자 enum이 아닌 전체 조회 필터로 검증하며 `StockOrderControllerTest`에서 HTTP 요청까지 확인합니다.

`node tests/ui-ux-browser.cjs`: 11개 화면 × 1440/390/320px, 문서 가로 넘침, 모바일 메뉴와 예정 목록, 조회 실패 후 재시도, 키보드 표 스크롤, 주문 모달, 거래 필터, 저장 중 중복 제출·Escape.

`node tests/stock-orders-browser.cjs`: 보유종목 주문, 계좌·거래소 선택, 매수/매도, 최종 확인, 확인 전 수정과 만료, 부분 체결·취소, 응답 유실, 페이징.

`node tests/snapshot-changes-browser.cjs`: 자산 변동 상세, 날짜·소유자·지표 필터와 모바일 조회.

`node tests/browser-smoke.cjs`: 기존 페이지·계좌·카드·할부·KB 내역·정렬 흐름.

브라우저 검증은 합성 데이터와 가짜 API 응답만 사용합니다. 실계좌 주문은 전송하지 않습니다. 화면 캡처는 추적하지 않는 `build/ui-review/`에 저장됩니다.

## 적용

앱을 재시작하고 브라우저에서 강력 새로고침(Ctrl+F5)하면 JSP와 CSS/JavaScript 변경을 함께 불러옵니다. WAR로 실행하는 환경은 새 WAR를 빌드하여 실행해야 합니다. 주문 활성화 설정은 이 작업에서 변경하지 않습니다.
