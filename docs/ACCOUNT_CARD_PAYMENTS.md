# 예정 거래의 계좌별 카드대금

예정 거래 달력에서 같은 결제 계좌·예정 출금일·결제월의 미처리 신용카드 결제를 하나로 표시합니다. 다른 결제일은 별도로 표시합니다. 소유자 필터는 결제 계좌 소유자를 기준으로 합니다.

계좌의 카드대금 항목을 열어 포함된 카드와 할부를 확인하고 실제 총 출금액을 한 번 입력합니다. 해당 계좌 잔액을 한 번 차감하고 모든 포함 카드의 해당 월 할부 회차를 함께 완료합니다. 원 단위 입력은 화면처럼 합계 전체를 반올림한 금액도 허용합니다. 소수 원을 직접 입력하면 원본 합계와 비교하며, 부족한 금액은 저장하지 않습니다. 잔액에서는 입력한 실제 금액만 차감하고 할부 원본의 소수 정밀도는 보존합니다. 날짜 변경과 예정 취소도 묶인 카드 전체에 적용합니다.

완료한 합산 결제는 하나의 출금 이력으로 보존합니다. 카드별 금액은 임의로 배분하지 않으며, 카드 상세 출금 이력에서는 ‘결제 계좌 전체 총액 (이 카드 포함)’으로 명시합니다. 기존 카드별 납부 이력은 유지됩니다. 카드 화면의 별도 카드대금 납부 기능은 단일 카드용으로 유지되며, 이미 계좌 결제로 완료한 카드·결제월을 다시 납부할 수 없습니다.

서버는 트랜잭션과 기존 전역 잠금을 사용하여 잔액·할부·완료 이력을 함께 저장합니다. 카드 목록이나 결제 계좌가 화면을 연 이후 변경되면 재조회를 요청합니다.

기존 DB에는 `gradlew migrateAccountCardPayment`를 실행한 후 앱을 재시작합니다. 이 마이그레이션은 `planned_occurrence.payment_group_id`와 인덱스만 추가하며 기존 잔액·납부 내역은 변경하지 않습니다. 새 DB에는 `db/schema.sql`에 포함되어 있습니다.
