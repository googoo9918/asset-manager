# 자산 추이 변동 내역

자산 추이 표에서 **이전 기록 대비 → 증감액 · 상세**를 누르면 비교 시각, 이전·이후 금액, 계좌·대출별 증감과 선택 지표에 반영된 금액을 확인할 수 있습니다. 대시보드, 전체 자산, 현금성 자산, 적금, 증권, 대출, 자산 스냅샷 화면에 공통 적용됩니다.

- 날짜는 한국 시간 기준이며 하루에 여러 번 저장했으면 마지막 기록을 사용합니다.
- 직전 기록이 조회 기간 밖에 있어도 비교 기준으로 사용합니다. 전날 기록이 없으면 직전 저장일을 기준일로 명시합니다. 최초 기록은 비교 대상이 없습니다.
- 소유자와 자산 지표 필터를 두 시점 각각에 적용합니다. 소유자·자산 유형 변경은 선택한 범위에서의 추가·제외로 반영될 수 있습니다.
- 순자산은 자산에서 대출을 뺀 금액입니다. 대출 감소는 순자산 증가로 표시합니다. 총부채 지표에서는 대출 잔액 자체의 증감을 표시합니다.
- 증권 계좌의 종목·예수금 변동을 펼칠 수 있습니다. 종목은 계좌 합계에 포함되므로 전체 변동 합계에 중복 가산하지 않습니다. 예수금·기타 잔액은 당시 계좌 총액에서 보유종목 평가액을 뺀 나머지입니다.
- 변동이 서로 상쇄되어 합계가 0원이어도 개별 변동을 표시합니다. 종목 ID가 갱신되어도 계좌·종목코드·통화가 같으면 같은 종목으로 비교합니다.
- 자산 스냅샷 화면의 **시점 비교**에서도 같은 상세 표시로 임의의 두 저장 시점을 비교할 수 있습니다.

기존 스냅샷 상세 API를 사용하므로 DB 변경은 필요 없습니다. 저장되지 않은 날짜의 잔액이나 입출금 사유는 복원하지 않습니다. 수량·가격·환율은 당시 값을 함께 표시하며, 각각의 인과적 기여액을 추정하지 않습니다. 갱신 결과를 함께 표시하므로 연동 실패 시점도 확인할 수 있습니다. 계산은 고정소수점으로 수행하고 화면에만 원 단위 반올림을 적용합니다.

검증: `node --test tests/snapshot-changes.cjs`, `node tests/page-modules.cjs`, `node tests/snapshot-changes-browser.cjs`. 브라우저 검증은 `tools/kb-card`의 Playwright와 설치된 브라우저를 사용하며 `PLAYWRIGHT_CHANNEL=msedge`로 Edge를 선택할 수 있습니다. 테스트는 가상 데이터로 수행하며 개인 DB에 접근하지 않습니다.
