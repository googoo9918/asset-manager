# 확인할 내역

`/review`에서 미분류 거래, 신용공여기간 미설정 카드, 기존 할부의 원거래 연결 검토 대상, 7일 이상 잔고가 갱신되지 않은 KIS 연결 계좌를 확인합니다. 대시보드에는 전체 건수를 표시합니다.

- 소유자 범위, 종류, 검색어로 필터링하며 한 페이지에 15건을 표시합니다.
- 하루 뒤에 보기는 브라우저 localStorage에 항목 ID·버전·만료 시각만 저장합니다. 다른 브라우저와 공유하지 않으며 내용이 변경되면 다시 표시됩니다. 대시보드 건수에는 미뤄둔 항목도 포함됩니다.
- 미분류 거래의 분류 수정은 MANUAL 원본 거래의 category_id만 변경합니다. 거래 ID, 금액, 잔액, 잔액 반영 내역, 기존 할부 연결은 유지합니다. entry_category_change에 이전·변경 분류를 기록하고 같은 트랜잭션으로 저장합니다. 조회 이후 분류가 변경되었다면 덮어쓰지 않습니다.
- 자동 등록 거래는 상세 조회만 제공합니다.
- 할부 연결 검토는 같은 카드·청구월에 겹치는 구매가 있다는 뜻입니다. 중복 확정이 아니므로 사용자가 원거래를 확인해야 합니다.
- 잔고 갱신은 계좌 last_synced_at 기준입니다. 시세의 정확성이나 거래소 영업일을 판정하지 않습니다.

## 반영

기존 DB는 백업 후 `gradlew.bat migrateReview --offline`을 실행하고 애플리케이션을 다시 시작합니다. 신규 DB에는 schema.sql에 이력 테이블이 포함됩니다. 마이그레이션은 반복 실행할 수 있으며 기존 잔액을 변경하지 않습니다.
