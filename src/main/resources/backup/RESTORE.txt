Asset Manager backup / 복원 안내

이 ZIP에는 PostgreSQL DB, 수집 전표 JSON, 복원 도구가 들어 있습니다.
API 키, DB 비밀번호, 브라우저 인증정보와 프로그램 본체는 포함하지 않습니다.
금융정보가 담긴 파일이므로 본인만 접근할 수 있는 별도 저장장치에 보관하세요.
DB는 일관된 스냅샷이며 전표는 생성 중 복사됩니다. 전표 수집이 끝난 뒤 백업하세요.

복원 절차 (Python 3 / PostgreSQL 도구 필요):
1. 앱과 수집 도구를 종료합니다. 보유 중인 신뢰할 수 있는 백업만 사용하세요.
2. ZIP에서 restore-backup.py만 꺼냅니다.
3. 먼저 검증: python restore-backup.py --archive backup-....zip --verify-only
4. 새 DB·새 폴더에 복원:
   python restore-backup.py --archive backup-....zip --database asset_restored --user asset_user --output-dir C:\DEV\asset-restored --pg-bin "C:\Program Files\PostgreSQL\18\bin"
   DB 비밀번호는 프롬프트로 입력합니다. 대상 DB 생성 권한이 필요합니다.
5. 결과를 확인하고 application-local.yml의 DB 주소를 새 DB로 변경합니다.
   출력 폴더의 data/kb-card를 앱 작업 폴더로 옮기기 전 기존 data/kb-card를 따로 보관하세요.
   원래 DB는 그대로 남습니다. 앱을 다시 실행하고 잔액·거래·전표를 확인하세요.

기존 DB나 기존 폴더로는 복원하지 않습니다. 복원 실패 시 새 DB에 잔여물이
남을 수 있습니다. 원인을 해결한 후 다른 새 DB 이름과 폴더로 다시 시도하세요.
해시 검증은 손상 탐지용이며 백업 발신자의 신뢰성을 증명하지 않습니다.
